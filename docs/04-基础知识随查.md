## A. Linux / Bash 命令速查

| 命令 | 本质 | 示例 |
|---|---|---|

### 重要符号对照

| 符号 | 作用 |
|---|---|
| `/` | Linux 路径分隔符；开头 `/` 表示绝对路径 |
| `~` | 当前用户的家目录 |
| `.` / `..` | 当前目录 / 父目录 |
| `$` | 普通用户的命令提示符（不是命令的一部分） |
| `\` | Bash 中行末续行符，下一行仍属同一命令 |
| `\|` | 管道，把前一命令标准输出接到后一命令标准输入 |
| `>` | 重定向：覆盖写文件；`>>` 是追加 |
| `-x` / `--example` | 命令短/长选项（含义由命令自身决定） |
| `Ctrl + C` | 通常发 SIGINT，中断前台命令 |
| `Esc` | 取消当前操作；曾解决 Windows 拖放卡住的问题（非 Linux 特有） |

> [!danger] 亲历易错：空格不是装饰
> `cd~/aiinfra-vllm`、`cd-aiinfra-vllm` 会被 Bash 当成**不同的程序名**，而不是执行 `cd`；`cd /aiinfra-vllm` 指 Linux 根目录下的文件夹，与家目录 `~/aiinfra-vllm` 不同。

### Nano 最实用的几个操作

- `Ctrl + O`：写文件；按 **Enter** 确认文件名。
- `Ctrl + X`：退出；如果未保存，会提示。
- `Ctrl + K`：剪切当前行或选区；`Ctrl + U`：贴回剪切内容。
- `Alt + A`：开始标记/选区；`Ctrl + _`：跳转行号。
- 粘贴在部分终端使用 `Ctrl + Shift + V` 或右键；Windows Terminal 可能提示多行代码粘贴警告。

## B. Python 基础概念

### Python 模块、类、对象与函数

```python
import statistics                      # 导入模块
from concurrent.futures import ThreadPoolExecutor  # 从模块导入类
pool = ThreadPoolExecutor(max_workers=4)            # 创建对象
print(statistics.mean([1, 2, 3]))                   # 调用函数
```

- **模块**是 Python 代码组织单元；**类**定义对象类型；**实例**是根据类创建的对象；**函数/方法**封装行为；`x.y()` 是在对象或模块上访问成员。

### `input()`、字符串、字典、列表

- `input()` 返回 `str`，即使输入 `1` 得到的是字符串 `'1'`，不是整数 `1`。
- `{ 'name': 'Qwen' }` 是字典，按 key 查找；`[1, 2, 3]` 是列表，按序号取值。
- `f'用户{i}：{PROMPT}'` 是格式化字符串，花括号中的表达式会被求值。

### JSON 与字节编码

```python
import json
payload = {'model': 'Qwen', 'messages': [{'role': 'user', 'content': '你好'}]}
wire_bytes = json.dumps(payload).encode('utf-8')
obj = json.loads(wire_bytes.decode('utf-8'))
```

JSON 是**传输/保存数据格式**，不是 Python 对象。`dumps` 序列化成字符串；`encode('utf-8')` 把字符转字节；`loads` 解析字符串。JSON 中布尔量是 `true`，Python 是 `True`。

### `with` 的本质：上下文管理器

```python
with open('result.csv', 'w', encoding='utf-8') as f:
    f.write('hello')
```

进入 `with` 时通过 `__enter__` 获取资源；离开时通过 `__exit__` 执行清理，即使抛异常也会触发收尾。**它不是制造并发的语法。**

```python
with ThreadPoolExecutor(max_workers=4) as pool:
    results = list(pool.map(send_request, range(4)))
```

线程池提供并发；`with` 在退出时 `shutdown(wait=True)` 等待已提交任务结束并回收资源。`range(4)` 产生 `0,1,2,3`；`pool.map` 将这些值分别传入函数。

### `try / except` 和 `finally`

```python
try:
    do_work()
except OSError as exc:
    print('I/O 失败', exc)
finally:
    cleanup()
```

`except` 处理符合类型的异常；`finally` 无论是否异常都会尝试执行，用来做清理。错误不应该被不加区别地吞掉；Benchmark 要计入失败请求。

### 循环、元组拆包、推导式

```python
results = [(256, 1.4), (256, 1.5)]
all_tokens = sum(tokens for tokens, _ in results)
```

`for tokens, _ in results` 取出每个二元组的第一个元素；`_` 表示故意不使用第二项。`list.append(x)` 添加**一个元素**，`extend(iterable)` 逐个添加元素。

### 单/双下划线

`matplotlib.__version__` 中 `version` **前后各两个**下划线，称 dunder。`_version_` 是完全不同的属性名。常见 `__name__`、`__init__`。

## C. 操作系统与网络基础

```mermaid
flowchart LR
 A[Windows 主机] --> B[WSL2 Linux]
 A --> C[Windows 代理本机 7890]
 B -->|HTTP/HTTPS 代理| C
 C --> D[外部网站 Hugging Face]
```

| 名词 | 一句话 |
|---|---|
| Terminal | 负责窗口、键盘输入、复制粘贴的终端程序 |
| Shell/Bash | 解析你输入的命令，决定执行哪个进程 |
| Ubuntu | 运行这些程序的操作系统发行版 |
| WSL2 | Windows 上运行 Linux 环境的虚拟化技术 |
| NAT | 地址转换，让虚拟网络经宿主机访问外部网络 |
| IP | 网络地址，标识网络接口或主机的可达位置 |
| Port | 一个主机上区分网络服务的编号；例如 8000 是 vLLM API |
| HTTP | 客户端/服务端请求-响应协议 |
| HTTPS | 使用 TLS 保护的 HTTP |
| DNS | 域名到网络地址等记录的解析服务 |
| Proxy | 由中间服务代客户端访问目标站点 |
| localhost / 127.0.0.1 | 回环地址，通常访问当前网络环境本身 |
| API | 提供给其他程序调用的接口 |
| SSE | Server-Sent Events，服务器分段向客户端推送文本事件 |

**关键纠正**：Windows 浏览器能上 Hugging Face ≠ WSL Linux 一定可以；模型下载需要联网，本机生成回答则不要求持续连接 Hugging Face。

## D. GPU / 推理栈概念

| 术语 | 你应记住的底层理解 |
|---|---|
| GPU | 适合高吞吐并行数值计算的硬件 |
| CUDA | NVIDIA 的 GPU 软件计算平台与生态 |
| CUDA Runtime | 执行现成 GPU 程序用的运行时组件 |
| nvcc | 编译 CUDA 源码的工具，属于开发工具链 |
| PyTorch | 张量计算框架，可调用 CUDA |
| Transformer | 模型的网络架构 |
| Hugging Face Transformers | 加载和执行模型的 Python 库 |
| vLLM | 面向在线推理服务的运行/调度/内存管理引擎 |
| FP16 / BF16 | 两种 16 位浮点数据类型，各有数值范围与精度特点 |
| Prefill | 处理输入上下文，建立中间状态与 KV Cache |
| Decode | 逐步生成后续 token 的过程 |
| KV Cache | 复用历史 token 的 Key/Value，减少重复计算 |
| FlashAttention | 更高效计算注意力的内核实现 |
| PagedAttention | 以块/页形式管理 KV Cache 的技术理念 |
| Continuous Batching | 按调度迭代动态加入/移除请求，不用固定整批等待 |
| TTFT | 从发出请求到收到首个生成输出的延迟 |
| TPOT | 输出首 token 后的平均每 token 时间 |
| P95 | 95% 的请求延迟不超过的观测值（取决于百分位定义） |

> [!important] 一定别混淆
> 总吞吐量 7000 tokens/s **不代表**任何单个用户能以 7000 tokens/s 阅读输出；它是同时处理所有请求的产出总和。
